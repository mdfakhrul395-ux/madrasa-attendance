মূল্যায়ন + সেমিস্টার পরীক্ষার নম্বর (marks-split.js)

বসানোর নিয়ম:
1. marks-split.js ফাইলটি GitHub রিপোজিটরিতে (বাকি ফাইলগুলোর সাথে, সবার উপরের স্তরে) আপলোড করুন।
2. index.html-এ সবার শেষে (final-result.js-এর পরে) এই লাইনটি যোগ করুন:
   <script src="marks-split.js"></script>
3. service-worker.js-এ CACHE_NAME-এর সংখ্যা এক বাড়ান।
   ফাইলের তালিকা (precache) থাকলে সেখানে "marks-split.js" যোগ করুন।

কী হবে:
- রেজাল্ট এন্ট্রিতে "প্রাপ্ত নম্বর"-এর বদলে মূল্যায়ন ও সেমিস্টার পরীক্ষার দুটি ঘর আসবে।
- প্রাপ্ত নম্বর = মূল্যায়ন + সেমিস্টার (স্বয়ংক্রিয়)।
- মার্কশিটে "প্রাপ্ত নম্বর"-এর আগে নতুন দুটি কলাম আসবে।
- গ্রেড, GPA, মেধাক্রম, চূড়ান্ত ফলাফল আগের মতোই থাকবে।
- পুরনো রেজাল্টে নতুন কলামে "–" দেখাবে।
