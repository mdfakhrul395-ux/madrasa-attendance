ব্যবহার-ট্র্যাকার (Usage Tracker) — সেটআপ নির্দেশনা
=====================================================

এই ফিচারটি কী করে:
- অ্যাপ নিজে প্রতিটা Firestore read/write/delete গুনে রাখে (আনুমানিক)
- আজকের মোট হিসাব একটা ছোট Firestore ডকুমেন্টে (usage_stats/YYYY-MM-DD) জমা হয়
- সুপার-অ্যাডমিন (mdfakhrul395@gmail.com দিয়ে লগইন করলে) একটা ফ্লোটিং 📊 বাটন দেখবেন,
  যেখানে ক্লিক করলে আজকের ব্যবহার বনাম ফ্রি লিমিট (৫০k reads / ২০k writes / ২০k deletes)
  দেখা যাবে

⚠️ এটা আনুমানিক হিসাব, Google-এর একদম নির্ভুল বিলিং সংখ্যা না। নির্ভুল সংখ্যা যাচাই করতে
মাঝে মাঝে Firebase Console → Usage and billing দেখে নেওয়া ভালো।

ধাপ ১: ফাইল আপলোড
------------------
usage-tracker.js ফাইলটা আপনার GitHub রিপোর repo root-এ (অন্য সব .js ফাইলের পাশে) আপলোড করুন।

ধাপ ২: index.html-এ স্ক্রিপ্ট ট্যাগ যোগ করুন
--------------------------------------------
firebase-config.js এর ঠিক পরে, app.js এর আগে এই লাইনটা যোগ করুন:

    <script src="usage-tracker.js"></script>

(অন্য extension স্ক্রিপ্টের মতো শেষে না দিয়ে শুরুর দিকে দিতে হবে, যাতে অ্যাপ চালু হওয়ার
প্রথম মুহূর্ত থেকেই সব read/write গোনা যায়।)

ধাপ ৩: Firestore rules আপডেট করুন
----------------------------------
firestore-rules-addition.txt ফাইলে দেওয়া অংশটুকু আপনার বর্তমান firestore.rules ফাইলে
যোগ করে Firebase Console থেকে (বা firebase deploy দিয়ে) rules পাবলিশ করুন।

⚠️ এই সংস্করণে শুধু isAdmin=true থাকা শিক্ষকরাই সংখ্যা পড়তে পারবেন। তাই নিশ্চিত করুন
mdfakhrul395@gmail.com একাউন্টটির teachers ডকুমেন্টে isAdmin: true সেট করা আছে —
নাহলে বাটনে ক্লিক করলেও ডেটা লোড হবে না (permission-denied দেখাবে)।

ধাপ ৪: টেস্ট করুন
------------------

ইত্যাদি) — নিচে ডানদিকে একটা 📊 বাটন দেখা উচিত। ৩০ সেকেন্ড পরপর সংখ্যা Firestore-এ
