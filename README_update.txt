আপডেট সারসংক্ষেপ
==================

এই app.js ফাইলে দুটি পরিবর্তন করা হয়েছে (রেজাল্ট/মার্কশিট অংশে):

১) রোল অনুযায়ী ধারাবাহিক তালিকা
   - "রেজাল্ট" ট্যাবের "সকল মার্কশিট" তালিকা এখন সবসময় ছাত্রের রোল নম্বর
     অনুযায়ী ক্রমানুসারে (ছোট থেকে বড়) দেখাবে — আগে এটি সেভের তারিখ
     অনুযায়ী সাজানো থাকত।
   - রোল সংখ্যায় না হলে (যেমন টেক্সট রোল) বাংলা/ইংরেজি বর্ণানুক্রমে সাজানো
     হবে, যাতে কখনো তালিকা এলোমেলো না দেখায়।

২) ভুল নম্বর এডিট করার অপশন
   - প্রতিটি সংরক্ষিত মার্কশিটের পাশে এখন "সম্পাদনা করুন" বাটন আছে
     (শুধু নতুন ফরম্যাটের মার্কশিটে যেখানে বিষয়ভিত্তিক তথ্য আছে)।
   - বাটনে চাপলে সেই মার্কশিটের সব বিষয় ও নম্বর ফর্মে লোড হয়ে যাবে, তখন
     প্রতিটি বিষয়ের পাশে "✎ সম্পাদনা" বাটনে চেপে নম্বর ঠিক করা যাবে।
   - "মার্কশিট সংরক্ষণ করুন" চাপলে এটি নতুন মার্কশিট না বানিয়ে একই
     মার্কশিট আপডেট করবে, এবং প্রকাশিত/অপ্রকাশিত অবস্থা যেমন ছিল তেমনই
     থাকবে (স্বয়ংক্রিয়ভাবে অপ্রকাশিত হবে না)।
   - এডিটের পর মেধাক্রম (merit rank) স্বয়ংক্রিয়ভাবে পুনরায় হিসাব হয়ে যাবে।

ইনস্টল করার নিয়ম:
1. এই app.js ফাইলটি আপনার GitHub রিপোর ঠিক আগের app.js-এর জায়গায় বসান।
2. GitHub-এ কমিট/পুশ করুন (অথবা GitHub Pages-এ আপলোড করুন)।
3. ব্রাউজারে অ্যাপ রিফ্রেশ করে পরীক্ষা করে দেখুন।

কোনো Firestore rules পরিবর্তনের দরকার নেই — শুধু app.js বদলালেই হবে।
