ডায়েরী (Diary) ফিচার আপডেট — ইনস্টল করার নিয়ম
=================================================

কী যোগ হয়েছে:
- শিক্ষক প্রতিদিনের ডায়েরি/হোমওয়ার্ক এন্ট্রি লিখতে পারবেন (তারিখ + শ্রেণি + লেখা + ঐচ্ছিক ফাইল/ছবি সংযুক্তি)
- ছাত্র শুধু নিজের শ্রেণির ডায়েরি এন্ট্রি দেখতে পারবে, সাথে সংযুক্ত ফাইল/ছবি দেখতে বা ডাউনলোড করতে পারবে
- ফাইল ফ্রি-টায়ারে রাখার জন্য Firebase Storage ব্যবহার করা হয়নি — ফাইলটি base64 আকারে সরাসরি Firestore-এ সংরক্ষিত হয় (সর্বোচ্চ ~৭০০KB সাইজ পর্যন্ত)

১) app.js আপডেট করুন
----------------------
১. আপনার GitHub রিপোতে যান: github.com/mdfakhrul395-ux/madrasa-attendance
২. app.js ফাইলে ঢুকুন → পেন্সিল (Edit) আইকনে চাপুন
৩. পুরো কনটেন্ট মুছে এই zip-এর app.js ফাইলের সম্পূর্ণ কনটেন্ট পেস্ট করুন
৪. নিচে "Commit changes" চাপুন

অন্য কোনো ফাইলে হাত দেওয়ার দরকার নেই (firebase-config.js, icon, manifest.json ইত্যাদি অপরিবর্তিত থাকবে)।

২) Firestore Security Rules-এ নতুন নিয়ম যোগ করুন
--------------------------------------------------
Firebase Console → Firestore Database → Rules-এ গিয়ে আপনার rules.match block-এর ভেতরে (অন্যান্য collection যেমন notices-এর rule যেখানে আছে, ঠিক তার পাশে) এই অংশটুকু যোগ করুন:

    match /diary/{docId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.token.email != null;
    }

এর মানে: লগইন করা যেকোনো ব্যবহারকারী (শিক্ষক/ছাত্র) পড়তে পারবে, কিন্তু শুধু ইমেইল/পাসওয়ার্ড দিয়ে লগইন করা শিক্ষকই লিখতে/মুছতে পারবেন।

যদি আপনার rules.txt-এর বর্তমান পুরো কনটেন্ট আমাকে পাঠান, তাহলে সঠিক জায়গায় বসিয়ে পুরো ফাইলটা তৈরি করে দিতে পারবো।

৩) পরীক্ষা করুন
------------------
- শিক্ষক হিসেবে লগইন করে "ডায়েরী" ট্যাবে যান, একটা শ্রেণি বেছে এন্ট্রি লিখে (চাইলে ছবি/ফাইল যুক্ত করে) সংরক্ষণ করুন
- ওই শ্রেণির যেকোনো ছাত্র হিসেবে ঢুকে "ডায়েরী" ট্যাবে গিয়ে এন্ট্রিটি দেখুন

মনে রাখবেন
------------
- ফাইল ৭০০KB-এর বেশি হলে আপলোড করা যাবে না (অ্যাপ নিজেই সতর্ক করবে) — ছবি/PDF দেওয়ার আগে সাইজ ছোট করে নিন প্রয়োজনে
- ছবি হলে সরাসরি প্রিভিউ দেখাবে, অন্য ফাইল (PDF ইত্যাদি) হলে ডাউনলোড লিংক দেখাবে
