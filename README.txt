ShikkhaOS — প্যাকেজ সিস্টেম, ধাপ ১ (সুপার অ্যাডমিন প্যাকেজ ঠিক করা)

এই জিপে ৩টি ফাইল আছে: plans.js (নতুন), index.html (শুধু একটি লাইন যোগ), firestore.rules।

আপলোডের ধাপ:
১. GitHub-এ plans.js নতুন ফাইল হিসেবে আপলোড করুন এবং index.html বদলে দিন।
   (index.html-এ শুধু exam-routine.js-এর নিচে <script defer src="plans.js"></script> লাইনটি যোগ হয়েছে)
২. Firebase কনসোল → Firestore → Rules এ firestore.rules-এর পুরো লেখা বসিয়ে Publish করুন।
   (শুধু madrasas অংশ বদলেছে: প্যাকেজের ফিল্ড plan, planExpiry, planUpdatedAt এখন শুধু আপনি লিখতে পারবেন)
৩. service-worker.js-এর CACHE_NAME-এর সংখ্যা একটি বাড়ান (আগের মতো)।

ব্যবহার:
আরও → সুপার অ্যাডমিন → যেকোনো মাদ্রাসার নিচে "প্যাকেজ ঠিক করুন" → প্যাকেজ বেছে মেয়াদ দিন
(+১ মাস / +৩ মাস / +১ বছর বাটন আছে) → সংরক্ষণ।

এই ধাপে প্যাকেজ দিলে বা মেয়াদ শেষ হলেও মাদ্রাসার কোনো কিছু আটকাবে না। আটকানো ধাপ ২ ও ৩-এ।
নোট ফিল্ড ইচ্ছে করে রাখিনি: madrasas ডকুমেন্ট ওই মাদ্রাসার সবাই পড়তে পারে।
