অ্যাপ আপডেট — ডায়েরী + পরামর্শ বক্স ইনস্টল করার নিয়ম
========================================================

কী যোগ হয়েছে (এই আপডেটে নতুন):
- "পরামর্শ" (Suggestion Box) ট্যাব — ছাত্ররা নিজের নাম-সহ পরামর্শ/মতামত পাঠাতে পারবে, শিক্ষক দেখতে পারবেন কে পাঠিয়েছে (শ্রেণি অনুযায়ী ফিল্টার-সহ), এবং মুছে ফেলতে পারবেন। ছাত্র নিজের আগের পাঠানো পরামর্শগুলোও দেখতে পারবে।

(আগের আপডেটে যোগ হওয়া "ডায়েরী" ফিচারও এই একই app.js-এ আছে — আগে থেকেই লাইভ থাকলে ঠিক আছে)

১) app.js আপডেট করুন
----------------------
১. GitHub রিপোতে app.js ফাইলে ঢুকুন → পেন্সিল (Edit) আইকনে চাপুন
২. পুরো কনটেন্ট মুছে এই zip-এর app.js-এর সম্পূর্ণ কনটেন্ট পেস্ট করুন
৩. "Commit changes" চাপুন

২) Firestore Rules আপডেট করুন
--------------------------------
১. Firebase Console → Firestore Database → Rules
২. বর্তমান rules-এর পুরো কনটেন্ট মুছে এই zip-এর firestore.rules ফাইলের সম্পূর্ণ কনটেন্ট পেস্ট করুন
৩. "Publish" চাপুন

এতে নতুন suggestions কালেকশনের নিয়ম যোগ হয়েছে: ছাত্র নিজের পাঠানো পরামর্শ পড়তে/পাঠাতে পারবে, শিক্ষক সব পড়তে ও মুছতে পারবেন।

৩) পরীক্ষা করুন
------------------
- ছাত্র হিসেবে লগইন করে "পরামর্শ" ট্যাবে গিয়ে একটা পরামর্শ পাঠান
- শিক্ষক হিসেবে লগইন করে "পরামর্শ" ট্যাবে গিয়ে দেখুন সেটা এসেছে কিনা, নাম ও শ্রেণি দেখা যাচ্ছে কিনা

মনে রাখবেন
------------
- যদি ছাত্র সাইডে "The query requires an index" এই ধরনের এরর দেখায় (ডায়েরীর সময় যেমন হয়েছিল), তাহলে এরর মেসেজের লিংকে চাপ দিয়ে ইনডেক্স তৈরি করে নিন — তবে এখানে সেই সমস্যা হওয়ার কথা না, কারণ এই কোয়েরিতে সরাসরি equality ফিল্টার ব্যবহার করা হয়েছে
