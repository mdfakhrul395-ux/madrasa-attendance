ডায়েরী ফিচার রিডিজাইন — আপলোড নির্দেশনা
========================================

কী পরিবর্তন হয়েছে
------------------
আপনার কাগজের লেসন রেজিস্টারের মতো করে "ডায়েরী" ফিচারটি বিষয়ভিত্তিক ফরম্যাটে
সাজানো হয়েছে। আগে শুধু একটি "লেখা" টেক্সটবক্স ছিল, এখন প্রতিদিনের এন্ট্রিতে
নিচের ফিক্সড বিষয়গুলো আলাদা আলাদা ঘরে দেখাবে (যেগুলোতে কিছু লেখা হবে শুধু
সেগুলোই এন্ট্রির তালিকায় দেখা যাবে):

  ১. কুরআন/তরীকায়ে তা'লীম
  ২. আরবি ১ম/আরবি লিখা
  ৩. আরবি ২য় পত্র
  ৪. বাংলা ১ম/২য় পত্র
  ৫. ইংরেজি ১ম/২য় পত্র
  ৬. গণিত/জ্যামিতি
  ৭. সমাজ/বিজ্ঞান
  ৮. আকাঈদ/ফিকহ
  ৯. হাদিস/মাসয়ালা
  ১০. কালিমা/দোয়া
  ১১. সাধারণ জ্ঞান/অঙ্কন

এছাড়া:
- "বার" (শনি/রবি/সোম... ) তারিখ থেকে অটোমেটিক বসে যাবে, টাইপ করতে হবে না।
- "তারিখ" এখনো একটি date picker (ডিফল্ট আজকের তারিখ), পরিবর্তন করলে বার-ও
  সাথে সাথে আপডেট হয়ে যাবে।
- ফাইল সংযুক্তি (attach) ফিচার আগের মতোই আছে (ঐচ্ছিক, সর্বোচ্চ ~৭০০KB)।
- পুরনো এন্ট্রি যেগুলো নতুন বিষয়ভিত্তিক ফরম্যাটে সেভ হয়নি, সেগুলো আগের মতো
  একক টেক্সট হিসেবেই দেখাবে (কিছু হারায়নি)।

Firestore rules
----------------
কোনো পরিবর্তন লাগবে না — "diary" কালেকশনের ডেটা স্ট্রাকচার ভেতরে ভেতরে একটু
পরিবর্তিত হয়েছে (এখন `subjects` নামে একটি object থাকে single `text`-এর বদলে/
পাশাপাশি), কিন্তু rules-এর কোনো ফিল্ড-লেভেল চেক ভাঙেনি।
