মোট শিক্ষার্থীর সংখ্যা দেখানো ফিচার
====================================

কী যোগ হলো:
- শিক্ষক অ্যাপের "শিক্ষার্থী" ট্যাবে, তালিকার উপরে এখন মোট শিক্ষার্থীর সংখ্যা দেখাবে।
- "সকল শ্রেণি" নির্বাচিত থাকলে: "মোট শিক্ষার্থী: X জন"
- কোনো নির্দিষ্ট শ্রেণি ফিল্টার করলে: "[শ্রেণি] শ্রেণিতে: Y জন (সর্বমোট: X জন)"

কোনো Firestore rules পরিবর্তন লাগবে না।

আপলোড করার ধাপ (GitHub Pages):
1. আপনার রিপোতে যান: github.com/mdfakhrul395-ux/madrasa-attendance
2. app.js ফাইলে ক্লিক করুন, তারপর পেন্সিল আইকনে (Edit) ট্যাপ করুন।
3. পুরনো কন্টেন্ট সব সিলেক্ট করে মুছে ফেলুন।
4. এই zip-এর app.js ফাইলের পুরো কন্টেন্ট পেস্ট করুন।
5. নিচে "Commit changes" চাপুন।
6. কয়েক সেকেন্ড পর লাইভ সাইটে গিয়ে (ব্রাউজার রিফ্রেশ করে) "শিক্ষার্থী" ট্যাব খুলে দেখুন — উপরে সংখ্যাটা দেখা যাবে।
