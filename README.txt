মেধাক্রম (মেরিট র‍্যাঙ্ক) আপডেট
================================

কী পরিবর্তন হয়েছে:
-------------------
১) যেসব শিক্ষার্থী পরীক্ষায় ফেল করেছে (গ্রেড F), তাদের মেধাক্রমে কোনো
   অবস্থান (১ম/২য়/৩য়...) দেওয়া হবে না। তাদের GPA আগের মতোই মার্কশিটে
   দেখানো থাকবে, শুধু মেধাক্রম বক্সটি দেখাবে না।

২) পাস করা শিক্ষার্থীদের মধ্যে মেধাক্রম এখন বাংলা ক্রমবাচক সংখ্যায়
   দেখানো হবে:
      ১ম, ২য়, ৩য়, ৪র্থ, ৫ম, ৬ষ্ঠ, ৭ম, ৮ম, ৯ম, ১০ম,
      ১১তম, ১২তম, ১৩তম, ... (১১ থেকে সব জায়গায় "তম")
   এবং মোট সংখ্যাও বাংলা সংখ্যায় দেখাবে (যেমন: "৩য় / ১২")।

কোথায় দেখা যাবে:
-----------------
- রেজাল্ট তালিকায় প্রতিটি মার্কশিটের পাশে "মেধাক্রম" ব্যাজ
- মার্কশিট বিস্তারিত দেখার পাতায় (viewMarksheet) মেধাক্রম বক্স

কীভাবে আপলোড করবেন:
--------------------
১) আপনার GitHub রিপোজিটরির (madrasa-attendance) app.js ফাইলটি খুলুন
২) এই zip-এর ভেতরের app.js ফাইলের পুরো কনটেন্ট দিয়ে সেটি সম্পূর্ণ
   প্রতিস্থাপন (replace) করুন
৩) Commit করুন
৪) অ্যাপে ঢুকে "রেজাল্ট" ট্যাবে গিয়ে "মেধাক্রম হালনাগাদ করুন" বাটনে
   চাপুন — এতে সব পুরনো মার্কশিটেও নতুন নিয়ম অনুযায়ী মেধাক্রম
   পুনরায় হিসাব হয়ে যাবে

কোনো firestore.rules পরিবর্তনের প্রয়োজন নেই।
