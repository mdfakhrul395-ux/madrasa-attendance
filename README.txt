উপস্থিতি ট্যাবে "লোড হচ্ছে..." আটকে থাকার সমস্যা — সম্পূর্ণ সমাধান
====================================================================

আসল কারণ (root cause) পাওয়া গেছে
----------------------------------
আপনার firestore.rules-এর attendance rule-এ:

    match /attendance/{docId} {
      allow read: if (isTeacherAuth() && resource.data.madrasaId == myMadrasaId()) || ...

যে ছাত্রের নির্দিষ্ট তারিখের attendance ডকুমেন্ট এখনো তৈরি হয়নি (দিনের শুরুতে
বেশিরভাগ ছাত্রের ক্ষেত্রেই এমন হয়, যেহেতু এখনো মার্ক করা হয়নি), তার জন্য
resource এর মান null। resource.data.madrasaId পড়তে গেলে rule নিজেই ব্যর্থ
হয়ে যায় -> পুরো read টাই permission-denied হয়ে যায়। এটাই কার্ড আটকে
থাকার আসল কারণ। (আপনার fees_monthly rule-এ এই সমস্যা ছিল না কারণ সেখানে
আগে থেকেই resource == null || যোগ করা ছিল -- attendance-এ ছিল না।)

এই আপডেটে দুইটা জিনিস ঠিক করা হয়েছে
-------------------------------------
১. firestore.rules -- attendance rule-এ resource == null || যোগ করা
   হয়েছে (fees_monthly-এর মতোই প্যাটার্ন), যাতে ডকুমেন্ট এখনো তৈরি না
   হওয়া অবস্থায়ও read করতে দেয়। এটাই মূল সমাধান -- এখন থেকে এই এরর আর
   হওয়ার কথা না।

২. app.js -- এখানে ভবিষ্যতে অন্য কোনো কারণে (নেটওয়ার্ক সমস্যা ইত্যাদি)
   লোড ব্যর্থ হলেও কার্ড চিরস্থায়ীভাবে "লোড হচ্ছে..." তে আটকে না থেকে
   এরর + রিট্রাই বাটন দেখায় -- এটা সেফটি-নেট, মূল সমাধান হলো rules ফিক্স।
   একই বাগ fees_monthly কার্ড লোডেও ছিল, সেটাও ঠিক করা হয়েছে।

কীভাবে আপলোড/পাবলিশ করবেন
---------------------------
১. Firebase কনসোলে যান -> Firestore Database -> Rules ট্যাব
২. বর্তমান rules-এর পুরো কনটেন্ট মুছে এই zip-এর firestore.rules ফাইলের
   কনটেন্ট পেস্ট করুন
৩. "Publish" চাপুন
৪. app.js GitHub রিপোতে আপলোড করে কমিট করুন (আগেই করে থাকলে বাদ দিন)
৫. অ্যাপ রিফ্রেশ করে (বা সম্পূর্ণ বন্ধ করে আবার খুলে) উপস্থিতি ট্যাবে
   গিয়ে চেক করুন -- এখন সব ছাত্রের কার্ড ঠিকমতো লোড হওয়ার কথা, একজনও
   "লোড হচ্ছে..." তে আটকে থাকবে না।
