পরীক্ষার রুটিন — নতুন ডিজাইন + সম্পাদনা বোতাম (ShikkhaOS)

কী আছে:
  exam-routine.js  — পুরনো exam-routine.js এর জায়গায় বসবে

আপলোডের নিয়ম:
  1. GitHub রিপোজিটরির মূল ফোল্ডারে পুরনো exam-routine.js এর বদলে এই ফাইলটি আপলোড করুন।
  2. service-worker.js এর CACHE_NAME এর সংখ্যা একটি বাড়িয়ে দিন (নতুন ডিজাইন সাথে সাথে দেখার জন্য)।
  3. index.html, style.css বা Firestore rules বদলাতে হবে না।

সম্পাদনা কীভাবে করবেন (শিক্ষক):
  আরও > পরীক্ষার রুটিন > যে রুটিনটি বদলাতে চান তার নিচে "সম্পাদনা" চাপুন।
  উপরের ফর্মে আগের তথ্য ভরা থাকবে — বদলে "পরিবর্তন সংরক্ষণ করুন" চাপুন।
  বাতিল করতে "বাতিল" চাপুন।

টিপ: সব সারির সময় হুবহু এক লিখলে সময় একবারই উপরে দেখাবে।
