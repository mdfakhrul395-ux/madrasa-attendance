মাদরাসার নাম ও লোগো — সেটিংস ফিচার আপডেট
===========================================

এই আপডেটে যা যোগ হয়েছে:
- শিক্ষকের নিচের ট্যাব বারে নতুন "সেটিংস" ট্যাব যোগ হয়েছে
- সেখান থেকে মাদরাসার নাম লেখা যাবে ও লোগো (ছবি) আপলোড করা যাবে (সর্বোচ্চ ~৫০০KB)
- সংরক্ষণ করার সাথে সাথে অ্যাপের উপরে একটা হেডার বার দেখাবে — লোগো + মাদরাসার নাম
  (শিক্ষক ও শিক্ষার্থী উভয়ের স্ক্রিনেই দেখা যাবে, রিয়েল-টাইমে সব ডিভাইসে আপডেট হবে)
- কিছু সেট না করা থাকলে আগের মতো "মাদরাসা হাজিরা অ্যাপ" লেখা দেখাবে

এটি সেটিংস আকারে বানানো হয়েছে (হার্ডকোড করা হয়নি), তাই ভবিষ্যতে যখন multi-tenant
সিস্টেমে যাওয়া হবে তখন প্রতিটি মাদরাসা তার নিজের নাম/লোগো আলাদাভাবে সেট করতে পারবে।

--------------------------------------------
ধাপ ১: GitHub রিপোতে app.js আপডেট করুন
--------------------------------------------
1. github.com/mdfakhrul395-ux/madrasa-attendance এ যান
2. app.js ফাইলে ক্লিক করুন
3. পেন্সিল (Edit) আইকনে চাপুন
4. পুরনো কন্টেন্ট মুছে এই zip-এর app.js ফাইলের পুরো কন্টেন্ট পেস্ট করুন
5. নিচে স্ক্রল করে "Commit changes" চাপুন

--------------------------------------------
ধাপ ২: Firestore-এ নতুন সিকিউরিটি রুল যোগ করুন
--------------------------------------------
Firebase Console > Firestore Database > Rules এ গিয়ে "students" কালেকশনের রুলের
মতো একই প্যাটার্নে "settings" কালেকশনের জন্য এই রুল যোগ করুন (isTeacher()
ফাংশনটি ইতিমধ্যে আপনার রুলে থাকার কথা, students কালেকশনের রুলে যেভাবে ব্যবহৃত
হয়েছে):

    match /settings/{docId} {
      allow read: if request.auth != null;
      allow write: if isTeacher();
    }

তারপর "Publish" চাপুন।

--------------------------------------------
ধাপ ৩: পরীক্ষা করুন
--------------------------------------------
1. লাইভ সাইটে (https://mdfakhrul395-ux.github.io/madrasa-attendance/) যান
2. শিক্ষক হিসেবে লগইন করুন
3. "সেটিংস" ট্যাবে গিয়ে মাদরাসার নাম লিখুন ও চাইলে লোগো আপলোড করুন
4. "সংরক্ষণ করুন" চাপুন
5. উপরে হেডার বারে নাম ও লোগো দেখা যাচ্ছে কিনা যাচাই করুন
6. একটি শিক্ষার্থী হিসেবে লগইন করেও একই হেডার দেখা যাচ্ছে কিনা যাচাই করুন

দ্রষ্টব্য: অ্যাপ আইকন (হোম স্ক্রিনের আইকন, icon-192.png/icon-512.png) এই আপডেটে
বদলানো হয়নি — সেটা এখনো ম্যানুয়ালি রিপ্লেস করতে হবে যদি হোম স্ক্রিনের আইকনও
মাদরাসার লোগো দিয়ে বদলাতে চান। এই ফিচারটি শুধু অ্যাপের ভিতরের হেডারের জন্য।
