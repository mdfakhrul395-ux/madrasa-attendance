অ্যাপ দ্রুত লোড হওয়ার আপডেট
============================

কী পরিবর্তন করা হয়েছে (শুধু index.html):

১. preconnect যোগ করা হয়েছে — Firebase সার্ভারের সাথে আগে থেকে সংযোগ তৈরি হবে, তাই স্ক্রিপ্ট লোড শুরু হতে দেরি হবে না।

২. সব <script> ট্যাগে defer যোগ করা হয়েছে — এখন HTML পেজটা আগে দেখা যাবে, স্ক্রিপ্টগুলো ব্যাকগ্রাউন্ডে লোড হবে (একটার পর একটা আটকে থাকবে না)। ফাইলগুলো ঠিক আগের অর্ডারেই (firebase SDK → firebase-config.js → app.js) লোড হবে, তাই কোড ভাঙবে না।

৩. প্রথম স্ক্রিনে "লোড হচ্ছে..." লেখা যোগ করা হয়েছে, যাতে ডেটা আসার আগে সাদা/ফাঁকা স্ক্রিন না দেখায়।

এই আপডেটে app.js, firebase-config.js, style.css, manifest.json, service-worker.js, icon — কোনোটাই পরিবর্তন হয়নি। শুধু index.html বদলেছে।


GitHub-এ আপলোড করার ধাপ (মোবাইল থেকে)
----------------------------------------
১. github.com/mdfakhrul395-ux/madrasa-attendance রিপোতে যান
২. index.html ফাইলে ক্লিক করুন
৩. ডান পাশে পেন্সিল (✏️) আইকনে ট্যাপ করে এডিট মোডে যান
৪. পুরনো কন্টেন্ট সব সিলেক্ট করে ডিলিট করুন
৫. এই জিপের index.html ফাইলের পুরো কন্টেন্ট কপি করে পেস্ট করুন
৬. নিচে স্ক্রল করে "Commit changes" চাপুন

কমিট হওয়ার ১-২ মিনিট পর লাইভ সাইট রিফ্রেশ করে দেখুন — পেজ আগের চেয়ে দ্রুত খুলবে।

কোনো Firestore rules পরিবর্তনের দরকার নেই।


পরে করা যায় (আরও বড় ইমপ্যাক্ট)
----------------------------------------
Firebase Auth SDK (teacher login-এর জন্য দরকার) student-দের জন্য অপ্রয়োজনীয়ভাবে লোড হয়। এটা lazy-load করলে (শুধু teacher বাটনে ক্লিক করলে তখন লোড হবে) student-দের initial load আরও কমানো যাবে। চাইলে বলবেন, পরের আপডেটে যোগ করে দেব।
