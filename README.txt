শিক্ষার্থীর নাম, রোল ও শ্রেণি সংশোধন
=====================================

১) student-edit.js ফাইলটি GitHub রিপোজিটরির মূল ফোল্ডারে আপলোড করুন (বাকি ফাইলগুলোর পাশে)।

২) index.html-এ dashboard.js-এর script লাইনের ঠিক নিচে এই লাইনটি যোগ করুন:

   <script src="student-edit.js"></script>

   (app.js, dashboard.js বা firestore.rules বদলাতে হবে না)

৩) অ্যাপ বন্ধ করে দুইবার খুলুন (পুরনো ক্যাশ সরাতে)।

ব্যবহার: অ্যাডমিন হিসেবে লগইন করে "শিক্ষার্থী" ট্যাবে যান। প্রতিটি শিক্ষার্থীর সারিতে
"✏️ সম্পাদনা" বাটন আসবে। সাধারণ শিক্ষক এটি দেখবেন না।

শ্রেণি বদলালে:
- পুরনো ফলাফল নতুন শ্রেণির মেধাতালিকায় যাবে, মেধাক্রম নিজে থেকেই নতুন করে হিসাব হবে
- হাজিরা, বেতন, ছুটির তথ্য অপরিবর্তিত থাকবে
- ডায়েরি নতুন শ্রেণির দেখাবে

যদি সংরক্ষণে "permission-denied" আসে, তাহলে আপনার বর্তমান firestore.rules পাঠান, আমি মিলিয়ে দেব।
