এডমিট কার্ড যোগ করার নিয়ম
=========================

এই জিপে ৩টি ফাইল আছে। তিনটিই GitHub রিপোর রুটে আপলোড করুন (পুরোনো ফাইলের উপরে বসবে):

  1) admit-card.js      — নতুন ফাইল
  2) index.html         — শুধু একটি লাইন যোগ হয়েছে (admit-card.js এর script ট্যাগ)
  3) service-worker.js  — admit-card.js তালিকায় যোগ, CACHE_NAME v76 থেকে v77

ব্যবহার:
"আরও" মেনু > এডমিট কার্ড > শ্রেণি ও পরীক্ষা বেছে "প্রিন্ট / PDF করুন"।

জেনে রাখুন:
- নতুন Firestore rule বা index লাগে না।
- পিতার নাম আসে student_contacts থেকে (যাদের পিতার নাম দেওয়া নেই, তাদের কার্ডে ঐ লাইন থাকবে না)।
- শিক্ষার্থীর ছবি শুধু অ্যাডমিন শিক্ষকের লগইনে কার্ডে আসে (ছবির নিয়মই তাই)। অন্য শিক্ষকের লগইনে নামের প্রথম অক্ষর দেখাবে।
- রুটিন আনতে একবার রিড লাগে; ছবির জন্য অ্যাডমিন লগইনে প্রতি শিক্ষার্থীর একটি করে রিড (সেশনে একবারই)।
