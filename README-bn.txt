চূড়ান্ত ফলাফল (১ম ২৫% + ২য় ২৫% + ৩য় ৫০%) — আপলোডের ধাপ

১) GitHub রিপোতে এই দুটি ফাইল আপলোড করুন (index.html আগেরটির জায়গায় বসবে):
   - final-result.js  (নতুন)
   - index.html       (শুধু শেষে একটি লাইন যোগ হয়েছে: final-result.js)

২) Firebase কনসোল > Firestore > Rules এ firestore.rules এর পুরো লেখা বসিয়ে Publish করুন।
   (শুধু একটি পরিবর্তন: মাদ্রাসার অ্যাডমিন যেন finalResultEnabled বদলাতে না পারে, শুধু সুপার অ্যাডমিন পারে)

৩) ব্যবহার:
   - ৩য় সেমিস্টারের মার্কশিট খুললে নিচে "পরীক্ষার চূড়ান্ত ফলাফল" দেখাবে।
   - পরীক্ষার নামে সেমিস্টার লেখা থাকতে হবে, যেমন "১ম সেমিস্টার ২০২৬", "২য় সেমিস্টার ২০২৬", "৩য় সেমিস্টার ২০২৬",
     আর তিনটির শিক্ষাবর্ষ একই হতে হবে।
   - শিক্ষক মার্কশিটে "অবস্থান হালনাগাদ করুন" চাপলে পুরো শ্রেণির অবস্থান হিসাব হয়ে শিক্ষার্থীদের কাছেও দেখাবে।
   - ৩য় সেমিস্টারের মার্কশিট সম্পাদনা করে আবার সংরক্ষণ করলে অবস্থান মুছে যায়, তখন আবার "অবস্থান হালনাগাদ করুন" চাপুন।
   - কোনো মাদ্রাসার জন্য বন্ধ করতে: সুপার অ্যাডমিন ট্যাবে ওই মাদ্রাসার নিচে "চূড়ান্ত ফলাফল: বন্ধ করুন"।

   - গ্রেড F হবে শুধু ৩য় সেমিস্টারে কোনো বিষয়ে ফেল থাকলে। ১ম/২য় সেমিস্টারে ফেল থাকলেও চূড়ান্ত গ্রেড জিপিএ অনুযায়ী আসবে।
