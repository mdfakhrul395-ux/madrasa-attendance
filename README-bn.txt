এডমিট কার্ড যোগ করার নিয়ম
=========================

এই জিপে ৩টি ফাইল আছে। তিনটিই GitHub রিপোর রুটে আপলোড করুন (পুরোনো ফাইলের উপরে বসবে):

  1) admit-card.js      — নতুন ফাইল
  2) index.html         — শুধু একটি লাইন যোগ হয়েছে (admit-card.js এর script ট্যাগ)
  3) service-worker.js  — admit-card.js তালিকায় যোগ, CACHE_NAME v76 থেকে v77

ব্যবহার:
"আরও" মেনু > এডমিট কার্ড > শ্রেণি বেছে পরীক্ষার নাম লিখুন > "প্রিন্ট / PDF করুন"।

জেনে রাখুন:
- কার্ডে রুটিন নেই। নতুন Firestore rule বা index লাগে না, রুটিনের কোনো রিডও লাগে না।
- প্রতি পাতায় ৬টি (সাশ্রয়ী) বা ৪টি (নির্দেশনাসহ) কার্ড, কাটার দাগসহ।
- ৪টি মোডে নির্দেশনা নিজে লিখে বদলানো যায় (প্রতি লাইনে একটি পয়েন্ট)। পরীক্ষার নাম ও নির্দেশনা এই ফোনে মনে থাকে।
- আসন নং ও কক্ষ নং-এর ঘর খালি থাকে, কলম দিয়ে লেখার জন্য।
- পিতার নাম আসে student_contacts থেকে (দেওয়া না থাকলে ঐ লাইন বাদ যায়)।
- শিক্ষার্থীর ছবি শুধু অ্যাডমিন শিক্ষকের লগইনে কার্ডে আসে (ছবির নিয়মই তাই)। অন্য শিক্ষকের লগইনে নামের প্রথম অক্ষর দেখাবে।
- ছবির জন্য অ্যাডমিন লগইনে প্রতি শিক্ষার্থীর একটি করে রিড লাগে (সেশনে একবারই)।
