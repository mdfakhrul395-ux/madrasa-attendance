# student_contacts আপডেট — ফোন/WhatsApp নম্বর সিকিউর করা

## কী পরিবর্তন হলো
আগে শিক্ষার্থীর মোবাইল নম্বর ও WhatsApp তথ্য `students` কালেকশনের মধ্যেই থাকত, আর
`students` read করার rule সবার জন্য খোলা (যেকোনো signed-in ডিভাইস, অন্য মাদরাসার
শিক্ষার্থীসহ)। এখন ফোন/WhatsApp নতুন `student_contacts` কালেকশনে সরানো হয়েছে, যেটা
শুধুমাত্র নিজ মাদরাসার শিক্ষক পড়তে/লিখতে পারবে — কোনো শিক্ষার্থী বা অন্য মাদরাসার
ডিভাইস কখনোই এটা পড়তে পারবে না।

`students` ডকুমেন্টে এখন শুধু থাকবে: নাম, রোল, শ্রেণি, hasPinSet — কোনো ফোন/WhatsApp
তথ্য থাকবে না।

## পুরাতন ডেটা migrate হবে কীভাবে
কোনো ম্যানুয়াল কাজ লাগবে না। নিচের ধাপগুলো শেষ করে শিক্ষক অ্যাকাউন্ট দিয়ে লগইন করার
সাথে সাথেই অ্যাপ নিজে থেকেই প্রতিটি বিদ্যমান শিক্ষার্থীর ফোন/WhatsApp তথ্য
`student_contacts`-এ কপি করে নেবে এবং `students` ডকুমেন্ট থেকে মুছে দেবে (একবারই হবে,
প্রতি মাদরাসার জন্য)।

## যা করতে হবে

1. **app.js আপডেট করুন**
   - GitHub রিপোতে (`madrasa-attendance`) গিয়ে `app.js` ফাইল খুলুন
   - সম্পূর্ণ কনটেন্ট মুছে এই নতুন `app.js` এর কনটেন্ট পেস্ট করুন
   - Commit করুন (main branch-এ)

2. **firestore.rules প্রকাশ করুন**
   - Firebase Console → Firestore Database → Rules ট্যাবে যান
   - বর্তমান rules সম্পূর্ণ মুছে এই নতুন `firestore.rules` এর কনটেন্ট পেস্ট করুন
   - "Publish" চাপুন

3. **যাচাই করুন**
   - লাইভ সাইটে গিয়ে শিক্ষক হিসেবে লগইন করুন (আগের মতোই)
   - "শিক্ষার্থী" ট্যাবে গিয়ে দেখুন সবার নাম/রোল/শ্রেণি ঠিকভাবে দেখাচ্ছে কিনা,
     এবং যাদের ফোন নম্বর দেওয়া ছিল তাদের নম্বর ও WhatsApp আইকনও ঠিকভাবে দেখাচ্ছে কিনা
   - নতুন শিক্ষার্থী যোগ করে ফোন নম্বর দিয়ে টেস্ট করুন
   - "নম্বর সম্পাদনা" বাটন দিয়ে একজনের ফোন পরিবর্তন করে দেখুন

## টেকনিক্যাল নোট
- migration চলাকালীন সাময়িকভাবে ডায়াগনস্টিক ব্যানারে কিছু বার্তা দেখা যেতে পারে —
  এটা স্বাভাবিক, migration শেষ হলে আর দেখাবে না
- migration flag localStorage-এ থাকে (`contactsMigrated_<madrasaId>`), তাই একবার
  সফল হলে বারবার চলবে না
- এই আপডেটে কোনো নতুন Firestore index লাগবে না
