# ডায়েরী আপডেট: মুছুন বাটন ফিক্স + বিষয় আলাদা করে লেখার সুবিধা

## ১) মুছুন (delete) বাটন কাজ করছিল না কেন
`firestore.rules`-এর diary কালেকশনে আগে একটাই রুল ছিল
(`allow write: if request.resource.data...`)। মুছে ফেলার (delete) সময়
Firestore-এ `request.resource` সবসময় `null` হয়ে যায়, তাই
`request.resource.data` পড়তে গিয়ে রুলটা এরর দিত এবং মুছার প্রতিটা
চেষ্টা "Missing or insufficient permissions" দেখিয়ে ব্যর্থ হতো — ঠিক
আগে students/attendance/results-এ যে একই সমস্যা হয়েছিল, সেই একই কারণ।

ঠিক করা হয়েছে rule-টাকে দুই ভাগে ভাগ করে:
- `allow create, update` — নতুন এন্ট্রি বা এডিটের জন্য
- `allow delete` — শুধু মোছার জন্য (এখানে `resource.data` ব্যবহার হয়, যা
  delete-এর সময়ও ঠিকমতো পাওয়া যায়)

## ২) যৌথ বিষয়ে একটি নির্দিষ্ট বিষয় বেছে লেখার সুবিধা
আগে "কুরআন/তরীকায়ে তা'লীম", "আরবি ১ম/আরবি লিখা", "গণিত/জ্যামিতি" ইত্যাদি
একসাথে জোড়া লাগানো একটা করে ফিল্ড ছিল। এখন প্রতিটা জোড়াকে দুইটা আলাদা
আলাদা (ঐচ্ছিক) ফিল্ডে ভাগ করা হয়েছে — যেমন এখন "কুরআন" ও "তরীকায়ে তা'লীম"
আলাদা বক্সে লেখা যাবে। যেকোনো একটাতে লিখলেই সেভ হবে, বাকিটা খালি রাখলে
সমস্যা নেই।

জোড়াগুলো (স্ক্রিনে পাশাপাশি দেখাবে):
- কুরআন / তরীকায়ে তা'লীম
- আরবি ১ম / আরবি লিখা
- বাংলা ১ম পত্র / বাংলা ২য় পত্র
- ইংরেজি ১ম পত্র / ইংরেজি ২য় পত্র
- গণিত / জ্যামিতি
- সমাজ / বিজ্ঞান
- আকাঈদ / ফিকহ
- হাদিস / মাসয়ালা
- কালিমা / দোয়া
- সাধারণ জ্ঞান / অঙ্কন
- আরবি ২য় পত্র (একাই, আগের মতো)

**পুরনো ডায়েরি এন্ট্রি** (যেগুলো আগে যৌথ ফিল্ডে সেভ হয়েছিল) ঠিক আগের মতোই
দেখাবে — কোনো ডেটা মাইগ্রেশনের দরকার নেই, app.js-এ সেগুলো এখনো চেনার
ব্যবস্থা রাখা আছে।

## আপলোড করার ধাপ
1. GitHub রিপোতে `app.js` ফাইলটা পুরনো ফাইলের জায়গায় replace করে commit করুন।
2. Firebase Console → Firestore Database → Rules ট্যাবে গিয়ে
   `firestore.rules`-এর পুরো কন্টেন্ট paste করে **Publish** করুন।
3. ফোনে অ্যাপ রিফ্রেশ করে (দরকার হলে সাইট ডেটা/ক্যাশ ক্লিয়ার করে) —
   - ডায়েরির "মুছুন" বাটন চেক করুন
   - নতুন এন্ট্রি ফর্মে "কুরআন" আর "তরীকায়ে তা'লীম" আলাদা বক্স হিসেবে
     দেখা যাচ্ছে কিনা দেখুন, একটাতে লিখে বাকিটা খালি রেখে সেভ করে
     পরীক্ষা করুন।
