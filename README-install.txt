index.html — আপডেট নির্দেশনা (পরামর্শ বক্সের উত্তর চালু করা)
================================================================

এই ফাইলে শুধু <script> ট্যাগের ক্রম বদলানো হয়েছে, যাতে
suggestion-patch.js (অ্যাডমিনের উত্তর দেওয়ার সুবিধা) চালু হয়ে যায়।

আগে ছিল:
  app.js → dashboard.js → tenant-link.js

এখন করা হয়েছে:
  app.js → suggestion-patch.js → dashboard.js → tenant-link.js

কেন এই ক্রম জরুরি:
  suggestion-patch.js অবশ্যই dashboard.js-এর আগে লোড হতে হবে।
  dashboard.js "হোম" ট্যাব ও অ্যাডমিন-সীমা যোগ করার সময় তার আগের
  teacherTab/renderTeacherNav ফাংশন wrap করে রাখে। উল্টো ক্রমে বসালে
  suggestion-patch.js-এর পরামর্শ-সংক্রান্ত বদল dashboard.js মুছে দেবে
  এবং হোম ট্যাব/ড্যাশবোর্ড ভেঙে যেতে পারে।

কীভাবে বসাবেন:
  ১. GitHub রিপোতে গিয়ে index.html খুলুন, পেন্সিল আইকনে (Edit) চাপুন।
  ২. পুরনো কনটেন্ট মুছে এই ফাইলের ভেতরের সম্পূর্ণ লেখা পেস্ট করুন
     (অথবা শুধু <script> লাইনগুলোর ক্রম মিলিয়ে বদলান)।
  ৩. নিচে গিয়ে "Commit changes" চাপুন।
  ৪. service-worker.js-এর ক্যাশ ফাইল তালিকায় (থাকলে) suggestion-patch.js
     যোগ আছে কিনা দেখুন, না থাকলে যোগ করে CACHE_NAME এক ধাপ বাড়ান।

পরীক্ষা:
  - অ্যাডমিন অ্যাকাউন্টে "আরও" মেনুতে "পরামর্শ" ট্যাব খুলুন।
  - কোনো পরামর্শের নিচে "উত্তর দিন" বাটন দেখা যাচ্ছে কিনা।
  - উত্তর লিখে সংরক্ষণ করার পর সেই শিক্ষার্থীর অ্যাকাউন্টে গিয়ে
    (বা তার ভিউ থেকে) উত্তরটি দেখা যাচ্ছে কিনা।
  - হোম ট্যাব ও অন্যান্য ট্যাবগুলো আগের মতোই কাজ করছে কিনা।
