tenant-link.js — ইনস্টলেশন নির্দেশনা
======================================

১. tenant-link.js ফাইলটি আপনার GitHub রিপোর মূল ফোল্ডারে আপলোড করুন
   (app.js, dashboard.js, index.html যেখানে আছে সেখানেই)।

২. index.html ফাইলে dashboard.js-এর লাইনের ঠিক নিচে এই লাইনটি যোগ করুন:

   <script defer src="tenant-link.js"></script>

   যেন ক্রম এমন দেখায়:
   <script defer src="app.js"></script>
   <script defer src="dashboard.js"></script>
   <script defer src="tenant-link.js"></script>

৩. service-worker.js ফাইলে ক্যাশের ফাইল তালিকায় (CACHE_FILES বা অনুরূপ অ্যারে) 
   'tenant-link.js' যোগ করুন এবং CACHE_NAME এক ধাপ বাড়ান (যেমন v12 থেকে v13),
   যাতে সবার ফোনে নতুন ফাইলটি ডাউনলোড হয়।

৪. GitHub Pages আপডেট হওয়ার পর (কয়েক মিনিট) অ্যাপ রিফ্রেশ করে পরীক্ষা করুন:
   - সেটিংস ট্যাবে "শিক্ষার্থী লগইন লিংক" কার্ড দেখা যাচ্ছে কিনা (প্রতিটি মাদ্রাসার নিজস্ব অ্যাডমিন এটি দেখবেন)
   - সুপার অ্যাডমিন ট্যাবে প্রতিটি মাদ্রাসার সারিতে লিংক ও কপি/হোয়াটসঅ্যাপ বাটন দেখা যাচ্ছে কিনা
   - প্রাইভেট/ইনকগনিটো ট্যাবে লিংকে ঢুকলে সরাসরি শ্রেণি বাছাই আসছে কিনা
   - লিংক ছাড়া "শিক্ষার্থী" চাপলে (এবং madrasa-001 না হলে) মাদ্রাসা কোড চাইছে কিনা
   - আপনার নিজের মাদ্রাসার (madrasa-001) শিক্ষার্থীরা লগআউট করার পরও আগের মতো সরাসরি শ্রেণি বাছাই পাচ্ছে কিনা (কোড চাইবে না)
